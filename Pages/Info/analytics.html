🔧 API Parameter Referenz

Zusätzliche Parameter für alle /metrics Aufrufe:

ParameterTypBeschreibung
startAt number Unix Timestamp (ms) des Anfangs
endAt number Unix Timestamp (ms) des Endes
type string Metrik-Typ (path, entry, exit, browser, os, device, country, city, language, screen, event, title, referrer, channel)
limit number Maximale Anzahl Ergebnisse
unit string Zeiteinheit für Zeitreihen (hour, day, month)
timezone string Timezone für Zeitformatierung (Europe/Berlin)
