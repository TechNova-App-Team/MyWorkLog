Vier Zahlen, und du weißt Bescheid.

Woche, Monat, Gleitzeit, Resturlaub. Jede Abweichung an einer sichtbaren Nulllinie mit bezifferten Enden — kein Ring, der einen Saldo als Fortschritt verkleidet.

Saldo-Trend

Dein Verlauf, nicht nur dein Heute.

Höchststand, Tiefststand, Tendenz auf einen Blick. Umschaltbar auf 7, 14, 30, 90 Tage oder die ganze Zeit.

Verteilung

Wohin die Stunden wirklich gehen.

Arbeit, Berufsschule, Krank, Urlaub, Feiertag — nach Anteil sortiert, in Stunden und Prozent. Ein Balken, fünf Kategorien, keine Deutung nötig.

Verlauf

Jeder Eintrag bleibt auffindbar.

Nach Typ filtern, in Notizen und Projekten suchen, als CSV oder JSON exportieren. Gelöschtes liegt im Papierkorb, nicht im Nichts.

Muster, die dir sonst entgehen.

iOS Safari

NFC-Schreiben nicht verfügbar

iOS Safari unterstützt Web NFC nicht. NFC-Chips können nur über Apps oder Android+Chrome programmiert werden.

Tipp für iPhone-Nutzer Du kannst NFC-Tags mit der "Kurzbefehle"-App lesen – aber nicht über den Browser schreiben. Bitte an einem Android-Gerät einrichten.
Desktop / Browser

Browser unterstützt kein NFC

Die Web NFC API ist nur in Chrome auf Android verfügbar (Chrome 89+).

Was tun? App auf deinem Android-Handy in Chrome öffnen und dort den Chip einmalig programmieren.
