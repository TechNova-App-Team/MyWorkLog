Farbe is a Chrome extension for selecting and inspecting colours. Farbe does not require an account, use analytics, show advertising, or send data to an external server.

Data processed

When you explicitly start the colour picker, Farbe temporarily captures the visible tab and processes that image locally in your browser to determine the colour at the position you click. The image is not uploaded and is not retained after the picker finishes.

Farbe stores recent and pinned colour values, the selected theme and view, and comparison values in chrome.storage.local on your device. This information is not transmitted, sold, or shared with third parties.

Permissions

activeTab and scripting are used only after you start the picker, so the picker overlay can run on the active page. storage saves local preferences and colour history. sidePanel provides the optional Chrome side panel view.

Limited Use

Farbe uses information received from Chrome only to provide its single purpose: selecting and inspecting colours. It does not use such information for advertising, profiling, creditworthiness, or any unrelated purpose. It does not transfer user data to people or organizations.

Changes and contact

If this policy changes, the updated version will be published on this page. For support, contact the developer through the support link on the Farbe Chrome Web Store listing.
