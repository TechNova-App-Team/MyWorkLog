NFC Chip Scanner
iOS Safari

NFC writing not available

iOS Safari doesn't support Web NFC. NFC chips can only be programmed via apps or Android+Chrome.

Tip for iPhone users You can read NFC tags with the "Shortcuts" app – but not write via the browser. Please set up on an Android device.
Desktop / Browser

Browser doesn't support NFC

The Web NFC API is only available in Chrome on Android (Chrome 89+).

What to do? Open the app on your Android phone in Chrome and program the chip there once.
Android Chrome ✓

Program your NFC chip once. After that a single tap is enough to clock in and out — without opening the app manually.
